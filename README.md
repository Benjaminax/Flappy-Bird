# Flappy Bird

A simple and addictive arcade game where you guide a bird through a series of pipes. Built with Unity, this project recreates the classic mobile game experience.

## Features

- **Classic gameplay:** Tap to keep the bird flying and avoid pipes.
- **Score tracking:** See how far you can go and beat your high score.
- **Simple controls:** One-button/tap gameplay for all ages.
- **Unity-powered:** Built using the Unity game engine for smooth performance.
- **Lightweight build:** Quick to download and play.

## Getting started

### 1. Clone the repository

```bash
git clone https://github.com/Benjaminax/Flappy-Bird.git
cd Flappy-Bird
```

### 2. Install dependencies

_No dependencies required for running the built game. To edit, open in Unity Hub._

### 3. Configure environment variables (if applicable)

_No environment variables are required._

### 4. Run the application

- Double-click `Flappy Bird.exe` to play.

### 5. Build for production

- Open the project in Unity and use the Build option for your target platform.
